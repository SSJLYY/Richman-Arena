# 前端设计与交互

前端为原生 HTML/CSS/JS 单页应用（`public/`），无框架、无构建。本文面向改 UI / 做视觉回归 / 复用设计系统的开发者。

## 视图与入口

- **大厅**（`#lobby`）：昵称 + 头像选择、创建/加入房间、房间列表、我的生涯战绩与成就墙、最近对局档案、重连上一局横幅。
- **对局**（`#mainApp`）：棋盘 + 玩家侧栏 + 操作区，顶部工具栏（趋势图 / 地产总览 / 回放 / 邀请）。
- 邀请链接 `?room=<房间号>`：进页自动填房号，已有昵称则直接加入。

## 主题系统（毛玻璃双主题）

- 颜色**只**定义在 `css/tokens.css`：`:root, [data-theme='dark']` 与 `[data-theme='light']` 两套变量；组件层只引用变量，不写死颜色。
- 组件层五个文件：`base / controls / panels / board / lobby`；其中**棋盘刻意保留浅色经典印刷风**，不随主题翻转。
- 切换入口：顶栏 🌗、设置面板、快捷键 <kbd>Shift</kbd>+<kbd>T</kbd>；选择存 localStorage（`monopoly_theme`）。
- 毛玻璃档位（`monopoly_glass`）：`full` 完整模糊 / `soft` 弱模糊 / `off` 完全不透明（性能差的设备）。

### URL 参数（视觉回归 / 截图对比用）

| 参数 | 作用 |
|------|------|
| `?theme=light\|dark` | 强制主题（优先于 localStorage，仅本次访问） |
| `?glass=full\|soft\|off` | 强制毛玻璃档位 |
| `?demo=1` | 自动单人开局并定时轮转操作，用于截取对局中画面 |
| `?ui=settings\|help` | 与 `?demo=1` 搭配，进场 600ms 后自动打开设置 / 帮助弹窗 |

## 棋盘渲染

- **增量渲染**：40 格骨架常驻复用；每格静态签名（名/色/价）不变则不重建，动态位（owner/level/mortgage/高亮）单独更新；换地图等静态变化自动回退整体重建。
- 测试断言「状态未变的格子复用同一 DOM 节点」，防回归（见 [testing.md](testing.md)）。
- 棋子层独立于格子层：逐格跳动动画（95ms/格，超过 12 格按传送滑动处理）；当前玩家棋子呼吸光晕；垄断组整组描边；拍卖地块脉冲、成交金光。
- 棋盘支持缩放（＋/－/⌂ 三个悬浮按钮）。

## 弹窗与无障碍

- 统一焦点陷阱：Tab 环内循环、ESC 关闭、关闭后焦点还原触发元素、多弹窗栈式管理。
- 对话框带 `role=dialog` / `aria-modal`；图标按钮与动态区（回合横幅、日志、金钱飘字）补 `aria-label` / `aria-live=polite`；skip link + 双主题可见 `:focus-visible` 焦点环。
- **不可跳过弹窗**：需要玩家决策的弹窗（购地确认、交易报价与还价、AI 求购）打开期间，快捷键（`h`/`T`/空格…）一律屏蔽，ESC 与遮罩点击被拒绝并抖动提示「请先完成当前操作」；纯信息弹窗仍可一键关闭。

## 移动端适配

- 两档断点（≤768px / ≤420px）：顶栏收缩不换行、棋盘占满宽度、侧栏纵向堆叠、操作栏贴底吸附；触控目标 ≥44px。
- 手机横屏（`landscape` 且高 ≤520px）：大厅头像缩小六列排布；对局改左右两栏（棋盘按视口高度收敛、操作面板置顶吸附），一屏内可见全部操作。
- 棋盘双指/按钮缩放，移动端默认给棋盘容器让出全高。

## 音效

WebAudio **合成**音效（`Sound` 模块，无外部音频文件）：掷骰 / 收租 / 付款 / 建造 / 回合轮到 / 抽卡 / 拍卖槌 / 筹钱告警 / 中奖 / 胜利 / 失败共 11 种；设置面板可开关与调音量（localStorage：`monopoly_sound` / `monopoly_volume`）。

## PWA

`manifest.json` + SVG 图标（普通 + maskable）：浏览器「添加到主屏幕 / 安装」后以独立窗口运行。**无 Service Worker**，不提供离线缓存（联网对战本身需要服务端）。

## 快捷键

| 键 | 功能 |
|----|------|
| `空格` | 掷骰 |
| `B` | 购买 |
| `E` | 结束回合 |
| `T` | 交易 |
| `P` | 保释 |
| `1 / 2 / 3` | 拍卖加价 +100 / +500 / +1000 |
| `Shift+T` | 切换主题 |
| `H` | 帮助 |

决策类弹窗打开时全部屏蔽（见上）。

## localStorage 键一览

| 键 | 内容 |
|----|------|
| `monopoly_token` | 玩家身份 token（重连凭据） |
| `monopoly_name` | 昵称 |
| `monopoly_room` | 最近房间号 |
| `monopoly_theme` / `monopoly_glass` | 主题 / 毛玻璃档位 |
| `monopoly_sound` / `monopoly_volume` | 音效开关 / 音量 |
