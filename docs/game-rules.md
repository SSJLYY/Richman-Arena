# 游戏规则详解

本文档描述服务端实际执行的规则与数值（以 `server.js` 为准），适合想了解玩法细节、调整平衡或二次开发的同学。

## 核心数值

| 常量 | 值 | 说明 |
|------|-----|------|
| 初始资金 | ¥15,000 | 房主可改为 8000 / 10000 / 15000 / 20000 / 30000 |
| 经过起点工资 | ¥2,000 | 精确停在起点不额外多发（避免双倍） |
| 保释金 | ¥1,000 | 支付后入奖池（奖池开启时） |
| 监狱上限 | 3 回合 | 第 3 回合强制交钱或掷双数失败后出狱 |
| 所得税 / 豪华税 | ¥2,000 / ¥1,000 | 奖池开启时入池 |
| 抵押 / 赎回 | 地价 50% / 50% × 1.1 | 赎回价为抵押价的 110% |
| 回合超时 | 120 秒 | 房主可改 30s / 60s / 120s，超时自动结束回合 |
| 单房间人数 | 最多 8 人 | 含机器人 |
| 银行房源 | 32 栋房 / 12 家酒店 | 售罄即不可再建（经典规则） |
| 双数规则 | 连续 3 个双数入狱 | 入狱后双数奖励清零 |

## 棋盘与地图

40 格经典布局（`BOARD_TEMPLATE`），支持三张地图，开局前由房主切换：

| 地图 | 特点 |
|------|------|
| 经典版 | 原版地名与价格，经济倍率 ×1 |
| 中国城市版 | 仅替换地名（兰州、北京、北京南站…），结构与平衡与经典版完全一致 |
| 武林风云版 | 武林门派地名 + **经济全面六折**（地价、租金、建造费 ×0.6），配合回合上限即 20 分钟快速局 |

地块类型：`city` 城市地产 · `railroad` 铁路 ×4 · `utility` 公用事业 ×2 · `chance` 机会 ×3 · `chest` 基金 ×3 · `tax` 税 ×2 · `go` 起点 · `jail` 监狱/参观 · `parking` 免费停车场 · `gotojail` 去监狱 · `casino` 赌坊（仅武林图，替换原"机会"格）。

## 回合流程

```
掷骰 → 棋子逐格移动 → 落地结算 → [决策阶段：购地/建房/交易/抵押] → 结束回合 → 下一位
```

- 掷出双数：结算完毕后**再掷一次**；连续 3 个双数直接入狱。
- 决策阶段：真人玩家掷骰后进入 `currentRolled` 状态，结束回合才交棒（防止误触跳过购地）。
- 回合上限（房主可设 20/30/50/80 回合）：到限时按**净资产最高者**获胜；团队模式按**全队净资产总和**定胜负。

## 监狱

入狱方式：踩「去监狱」、抽到入狱卡、连续 3 个双数。

出狱方式（按优先级）：
1. 使用「出狱免费卡」（机会 / 基金各有一张）；
2. 支付保释金 ¥1,000（入奖池）；
3. 掷双数（3 回合内成功即免费出狱并按点数移动，第 3 回合失败则强制缴费出狱）。

狱中可以正常收租、交易、建房，但不能移动。

## 购地、建造与租金

- **购地**：踩中无主地产，回合内决策阶段可按地价购买；放弃购买或超时不买 → 触发**拍卖**（拍卖开启时）。开启「自动购买」后，落地即买（需余额 ≥ 地价 + ¥200）。
- **建造**：必须**集齐同色组**才可建房；同组内**均匀建造**（只能盖在组内等级最低的地块上，最高 5 级=酒店）。卖房同样均匀（从等级最高的拆）。
- **租金**：

| 地块 | 租金规则 |
|------|----------|
| 城市空地 | 基础租金；集齐同色组 ×2 |
| 城市 1~4 房 / 酒店 | 按 6 级租金表（`GROUP_INFO.rents`），随等级跳涨 |
| 铁路 | 拥有 1/2/3/4 条：¥250 / 500 / 1000 / 2000 |
| 公用事业 | 骰子点数 × 40（拥有一家）/ × 100（独占两家）；「租金10倍」卡 = 点数 × 100 |

- 抵押中的地块不收租；租金结算走统一 `charge()` 通道，付不起自动进入筹钱期。

## 卡牌

机会 14 张、基金 13 张，洗牌后循环抽取。特殊处理：

- 「前进到某地」卡：传送后**重新执行落地结算**（可能交租 / 购地 / 再抽卡）；
- 「前进到最近铁路，租金×2」「电力公司租金10倍」：带租金加成标记；
- 「后退3格」：同样重新结算落地；
- 修缮 / 维修费：按名下建筑数计算（每栋房 ¥250/¥400，每家酒店 ¥1000/¥1150）；
- 「生日收礼」：向每位在场玩家收 ¥500（对方现金不足只收剩余）；
- 卡面扣款导致现金为负时，不直接判负，缺口自动转入**筹钱期**。

## 拍卖

- 触发：真人踩中无主地放弃购买 / 决策超时（房主可整体关闭拍卖）。
- 底价 ¥100，**加价步进固定 ¥100**（防止 1 元加价拖延）；出价不能超过自己现金。
- 总时长 20 秒；**最后 5 秒内有人加价自动顺延 5 秒**，整场封顶 60 秒。
- 成交：最高价者付款得地；无人出价流拍。
- 机器人会按估值参与竞价（差一块成套时志在必得，估值上浮 1.6 倍），团队模式下不与队友抬价。
- 同一时刻全场只允许一场拍卖，其余请求顺延提示。

## 交易与 AI 求购

- **玩家间交易**：现金 + 地产双向组合，需**对方确认**才生效，30 秒未响应自动作废；有欠款在身的玩家不能发起。
- **AI 求购提案**：机器人集齐某色组只差一块时，可能主动向真人屋主出价求购（无建筑地块，报价为地价 1.2~1.6 倍，困难档 1.5~1.8 倍更慷慨），15 秒内接受即成交；同一地块同一机器人只提案一次。
- 团队模式下不与队友交易 / 抬价。

## 奖池与赌坊

- **奖池**（可开关）：所得税、豪华税、保释金进入奖池；踩中「免费停车场」赢走全部奖池。
- **赌坊**（武林图专属，36 号格）：五五开豪赌，赌注 = min(¥360×经济倍率, 全部现金)，身无分文时庄家免单。

## 欠款、筹钱期与破产

1. 付不起租金 / 税款 / 费用 → 进入 **30 秒筹钱期**，期间该玩家回合暂停，全场等待；
2. 自救手段：卖房（先拆高级）→ 抵押地产 → 与他人交易；
3. 筹钱期内现金够了立即自动结算欠款；
4. 期限到仍不够 → **破产清算**：全部地产先退回银行（建筑作废）、再移交债主（有债主时），出狱免费卡一并转移；
5. 无债主（税 / 卡 / 赌坊）时资产归银行；
6. 破产玩家标记 `bankrupt`，不再参与回合，棋子与资产面板沉底显示。

## 团队模式（2v2）

- 加入房间时按座位分 2 队（红 / 蓝）；
- 踩队友地块**免租通行**；
- 队友之间不收租、不竞价、不求购；
- 结束条件：只剩一支队伍存活，或回合上限到时按全队净资产总和定胜负；
- 战绩额外记录 `teamWins`（并肩作战成就）。

## 胜负与结算

- **淘汰制**：只剩一名非破产玩家即获胜。
- **回合上限**：到时净资产最高者（团队按总和）获胜。
- 结算画面：本局之最（最大单笔租金、购地王…）、最繁忙地段（到访热力）、掷骰点数分布直方图、净资产走势图、可进入**逐轮回放**。
- 真人玩家的战绩（场次 / 胜场 / 巅峰净资产 / 累计租金 / 掷骰 / 入狱 / 购地）持久化到 `data/stats.json`，大厅显示排行榜与 8 枚生涯成就徽章；最近 20 条对局档案存 `data/history.json`。
