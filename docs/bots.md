# 机器人与托管 AI

服务端内置三层"AI"：**独立机器人**、**托管代打**、**掉线接管**。三者共用同一套决策逻辑（`server.js` 的 `bot*` 系列函数），只是触发来源不同。

## 三档难度

| 行为 | 简单 easy | 普通 normal（默认） | 困难 hard |
|------|-----------|---------------------|-----------|
| 买地决策 | 35% 概率犯懒不买 | 现金缓冲 ¥1800（差一块成套时降到 ¥800） | 现金缓冲仅 ¥300，激进扫货 |
| 建房上限 | 最多盖到 2 级 | 盖满 5 级（酒店） | 盖满 5 级 |
| 建房现金缓冲 | ¥4000 | ¥2500 | ¥1500 |
| 赎回抵押 | 从不赎回 | 保留 ¥5000 时赎回 | 保留 ¥2500 时赎回 |
| 主动求购提案 | 8% 概率/轮 | 20% | 35%，出价 1.5~1.8 倍更慷慨 |
| 交易评估阈值 | 给出价值 ×1.5 才收 | ×1.15 | ×0.95（接近等价就收） |
| 保释倾向 | 有钱也不交，蹲满 3 回合 | 保留 ¥3000 时交保释金 | 只需保留 ¥1000 就交 |

机器人名字固定池（阿福 / 贝贝 / 旺财 / 来福 / 豆豆 / 球球 / 布丁），头像 🤖，不会占用真人重连 token。

## 决策行为清单

**掷骰与监狱**（`botRoll`）：优先用免费卡 → 有钱交保释 → 否则掷双数碰运气。

**买地**（`botTryBuy`）：落地无主地产时按难度现金缓冲决定；差一块成套的地块会降缓冲抢购。

**建造**（`botBuildStep`）：集齐成套后逐步均匀盖房，遵守银行 32 房 / 12 酒店库存。

**拍卖**（`scheduleBotBids` / `auctionValue`）：对地块估值后参与竞价；已拥有同组地块估值上浮 1.3 倍，**差一块成套上浮 1.6 倍志在必得**；团队模式下不与队友抬价；随机延迟出价模拟真人思考，偶尔在聊天里吐槽。

**求购**（`maybeBotProposeTrade`）：每轮小概率向真人屋主出价求购"成套缺口地"，只求购无建筑地块，15 秒不回应自动收回。

**交易评估**（`botEvaluateTrade`）：按地价 + 建筑投入估算双方得失，收到价值 ≥ 给出价值 × 阈值才接受。

**自救**（`botSettleDebt`）：筹钱期内按"紧急卖楼 → 抵押"顺序自动筹钱，仍不够则破产清算。

**闲聊**（`botSay`）：交租 / 收租 / 入狱 / 拍卖 / 获胜等场景小概率在聊天区发言，增加人气。

## 托管与接管

| 场景 | 行为 |
|------|------|
| 玩家点「托管」 | `delegated=true`，之后每步由 AI 代打，可随时取消收回控制权 |
| 玩家主动退出 | 席位立即由机器人接管，**保留全部资产与昵称**（改名加 🤖 标记），重进房间可收回 |
| 玩家掉线 | **立即自动托管**（AI 代打，重连即恢复手动）；掉线满 5 分钟才正式由机器人接管席位 |

托管的真人也会参与"AI 求购提案"决策（作为发起方），但掉线托管中不向他人提案。

## 调速

房主可将机器人速度调为 0.4 倍（`botSpeed`），所有 bot 定时器延迟统一放大 2.5 倍，适合观赛或截图。真人玩家节奏不受影响。

## 实现要点（二次开发参考）

- 所有 bot 动作通过 `botAddTimer(room, fn, delay)` 调度：房间销毁、游戏重置时统一 `clearBotTimers` 清理，防止幽灵定时器。
- bot 决策之间有 900ms~1s 的固定延迟 + 随机抖动，模拟真人操作节奏，前端据此播放棋子逐格动画。
- bot 不会做超出规则的事：全部走与真人相同的 `socket` 处理函数对应的内部函数（买地 / 建房 / 出价 / 交易），保证规则一致性。
